# Culture Wars

Mobile real-time strategy game (three.js + Vite). Lighthearted subculture factions fight over a city,
built on the structure of Battle for Middle-earth II.

- `npm install && npm run dev` — play on your phone over the local network
- `npm run build:artifact` — one self-contained HTML file in `dist-artifact/`

Start with `CLAUDE.md` (rules + architecture), then `docs/design.md`, `docs/decisions.md`, `docs/agents.md`.
